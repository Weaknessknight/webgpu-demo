WebGPU: вычисления на GPU

Демо запускает compute shader: GPU параллельно вычисляет значения синусоидальной функции, затем результат считывается и отображается на Canvas.

Результат вычислений

После запуска здесь появится время выполнения и число вычисленных элементов.

Что происходит внутри?

  1. JavaScript запрашивает GPU-адаптер и устройство.
  2. Создаётся буфер для результата.
  3. WGSL compute shader получает уникальный индекс каждого элемента.
  4. GPU вычисляет sin(x) × cos(3x) для каждого элемента параллельно.
  5. Результат копируется обратно в память CPU и рисуется на Canvas.

Это учебный пример. В реальных приложениях частое чтение данных обратно на CPU может снизить производительность.
