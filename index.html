Нажмите «Сравнить CPU и GPU», чтобы выполнить измерения на нескольких размерах данных.

Время GPU включает отправку команд, ожидание и копирование результата обратно в память CPU (readback). Это end-to-end измерение, а не только время работы шейдера. Время CPU — медиана повторных запусков после прогрева.

Как устроено вычисление

CPU — JavaScript

Циклы последовательно обходят пиксели и соседние точки. Для каждого пикселя рассчитывается среднее значение окрестности (Box Blur) или градиент яркости (Sobel).

GPU — WGSL

Compute shader запускает множество потоков. Один invocation обрабатывает один пиксель. Workgroup имеет размер 8 × 8, а dispatchWorkgroups распределяет блоки по изображению.

Данные передаются в GPU storage buffer, параметры — в uniform buffer. После вычисления результат копируется в readback buffer и отображается на Canvas. Для маленьких массивов накладные расходы на передачу данных и запуск GPU могут быть больше выигрыша от параллелизма.
